# Default
This is the current default drone used in the project. It is a hexacopter design and it is designed in [FreeCAD](https://www.freecad.org) but it is by no means a complete drone design. 

Its major faults:
* Lacks electronics and no consideration for there implementation,
* Missing connections(some connections are not fastened by any means)
* All blades go in the same direction
* No testing and little consideration for functionality has been taken, it is designed to look good.

But it is by no means useless as a start or as a CAD reference.
